# CreditWise Loan System

CreditWise Loan System is a Machine Learning based project that predicts loan approval using applicant-related information.

## Features

- Data preprocessing
- Exploratory Data Analysis
- Data visualization
- Feature engineering
- Machine Learning model
- Model evaluation
- Loan approval prediction

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells sequentially.
